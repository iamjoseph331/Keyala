About, privacy and support

MasterKey beta. Updated 19 November 2026.

This is a personal experimental project. It is run by Joseph Chen, actively developed and carefully tested, but it is not an enterprise service: no uptime guarantee, no service level agreement, and it can change or stop. Do not rely on it for anything critical.

What it does

You store your own AI provider key (OpenAI, Anthropic or OpenRouter) on this server. An app asks permission through MasterKey, you approve on your phone, and the server forwards that one request to the provider with your key. The app never receives the key.

Your keys and requests

  • Provider keys are encrypted at rest. The server decrypts a key in memory to forward a request you allowed, so the operator of this server can technically access it. You are trusting the operator.
  • Requests and responses (the prompt, the reply, timestamps, model and computed cost) are stored so you can review them in the app. They are kept until you delete your account; there is no automatic expiry yet.
  • Data goes to: the provider you chose (your key and the request), the app that made the request (the response), and the hosting service this server runs on. Your sign-in identity comes from Apple or the operator's own login.
  • Developer reports are aggregates only (counts, cost, model, country code). They never include prompts, responses, keys or personal identifiers.
  • The server never returns a stored original key in API responses (only the last four characters) and never puts a key into a generated link or QR code. The add-key page briefly holds the key you paste into it. Keys are not written to logs. Never send a key in a support email.

Deleting things

In the app you can remove a key, disconnect an app, stop all apps, sign out everywhere and delete your account (which removes your keys, permissions, requests and responses from the live database). Deleting does not recall requests already sent to a provider or copies an app or provider kept. Operator backups, if enabled, are replaced on a rolling schedule and are not erased instantly; a deleted account is removed again if a backup is ever restored.

Cost

The beta is free. Your provider bills you separately for every request you allow; MasterKey shows an estimate before you approve, and the final cost is derived from the usage the provider reports, not from an invoice.

運作方式

你把自己的 AI 供應商金鑰（OpenAI、Anthropic 或 OpenRouter）存放在此伺服器。App 透過 MasterKey 請求許可，你在手機上核准後，伺服器才用你的金鑰把那一次請求轉送給供應商。App 不會拿到金鑰。

你的金鑰與請求

  • 供應商金鑰以加密方式儲存。伺服器為了轉送你允許的請求，會在記憶體中解密金鑰，因此本伺服器的營運者在技術上能存取金鑰。你必須信任營運者。
  • 請求與回應（提示內容、回覆、時間、模型與計算出的費用）會保存，方便你在 App 中查看。保存到你刪除帳號為止，目前沒有自動到期機制。
  • 資料會送到：你選擇的供應商（金鑰與請求）、發出請求的 App（回應），以及本伺服器所在的主機服務。登入身分來自 Apple 或營運者自己的登入方式。
  • 開發者報表只有彙總資料（次數、費用、模型、國家代碼），不含提示內容、回應、金鑰或個人識別資訊。
  • 伺服器不會在 API 回應中回傳已儲存的原始金鑰（只回傳末四碼），也不會把金鑰放進產生的連結或 QR code。新增金鑰頁面會暫時持有你貼上的金鑰。金鑰不會寫入日誌。請勿在支援信件中寄送金鑰。

刪除資料

你可以在 App 中移除金鑰、中斷 App 連結、停止所有 App、登出所有裝置，以及刪除帳號（會從運作中的資料庫移除金鑰、授權、請求與回應）。刪除無法收回已送給供應商的請求，也無法刪除 App 或供應商自行保存的副本。營運者的備份若有啟用，會依輪替排程更新，不會立即清除；若日後還原備份，已刪除的帳號會再次被移除。

費用

Beta 免費。供應商會就你允許的每個請求另外向你收費；MasterKey 會在核准前顯示估算值，最終費用依供應商回報的用量計算，並非帳單金額。

概要、プライバシー、サポート

MasterKey ベータ版。更新日：2026 年 11 月 19 日。

これは個人の実験的プロジェクトです。Joseph Chen が運営し、継続的に開発し丁寧にテストしていますが、企業向けサービスではありません。稼働率の保証や SLA はなく、仕様の変更や終了もあり得ます。重要な用途には使わないでください。

しくみ

ご自身の AI プロバイダーのキー（OpenAI、Anthropic、OpenRouter）をこのサーバーに保存します。アプリは MasterKey を通じて許可を求め、あなたがスマートフォンで承認すると、サーバーがそのリクエスト 1 件をあなたのキーでプロバイダーに転送します。アプリがキーを受け取ることはありません。

キーとリクエストについて

  • プロバイダーのキーは暗号化して保存されます。許可したリクエストを転送するため、サーバーはメモリ上でキーを復号します。そのため、このサーバーの運営者は技術的にキーへアクセスできます。運営者を信頼していただく必要があります。
  • リクエストとレスポンス（プロンプト、返答、日時、モデル、計算した費用）は、アプリで確認できるよう保存されます。アカウントを削除するまで保持され、自動的な期限はまだありません。
  • データの送信先：選択したプロバイダー（キーとリクエスト）、リクエストしたアプリ（レスポンス）、このサーバーが動作するホスティングサービス。ログイン情報は Apple または運営者独自のログインに由来します。
  • 開発者レポートは集計のみ（件数、費用、モデル、国コード）で、プロンプト、レスポンス、キー、個人を特定できる情報は含みません。
  • サーバーは、保存済みの元のキーを API のレスポンスで返すことはなく（末尾 4 文字のみ）、生成するリンクや QR コードにキーを含めることもありません。キーの追加ページは、貼り付けられたキーを一時的に保持します。キーはログに書き込まれません。サポートへのメールにキーを送らないでください。

削除について

アプリでは、キーの削除、アプリの接続解除、すべてのアプリの停止、全端末からのログアウト、アカウント削除ができます（稼働中のデータベースからキー、許可、リクエスト、レスポンスが削除されます）。送信済みのリクエストの取り消しや、アプリやプロバイダーが保持するコピーの削除はできません。運営者のバックアップは、有効な場合に順次入れ替わり、即時には消去されません。バックアップを復元した場合も、削除済みのアカウントは再度削除されます。

費用

ベータ版は無料です。許可した各リクエストについて、プロバイダーから別途請求されます。MasterKey は承認前に見積もりを表示し、最終的な費用はプロバイダーが報告した使用量から算出するもので、請求書の金額ではありません。
