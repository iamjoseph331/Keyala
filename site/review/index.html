Keyala

Review a request, without provider charges

This tool connects only to Keyala's separate review server. Its responses and costs are simulated. Never enter a real provider key or private text here. The free server may take a minute to wake up; its test data can reset.

1. Prepare the iPhone app

  1. Open Settings → Developer options. Enable developer options, keep Use sample data off, then select Use review server.
  2. Open Settings → Account and sign in with the review username and password supplied privately in App Store Connect.
  3. In Keys, add an OpenAI key using this fictional value: sk-proj-REVIEWFAKE0000.

Server: https://keyala-review.onrender.com. Production accounts and keys are separate.

2. Connect this tool

Scan this QR using the scanner inside Keyala, or enter the code in the app. Choose Connect and ask each time. If you see Choose access instead, keep Once and tap Apply access.

Open code in Keyala on this phone

3. Allow, deny, then revoke

Send the fictional prompt “Say hello to the Keyala reviewer.” Open Inbox on the iPhone and choose This call only. Check the response and Activity history. Send another request and choose Deny. Finally, revoke this tool in Apps, then send again to verify access has stopped.

Ready to connect.

Each press sends once. A network failure is never automatically retried. Reloading this page forgets its connection token; revoke the old grant in the app if you no longer need it.

Account deletion can be tested using the disposable review account in Settings → Account. Sign in again with the same supplied password to recreate it. Push notifications and real Apple sign-in require separate production verification.
