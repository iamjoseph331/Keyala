Keyala 想回答一個問題：AI 應用程式需要模型 API key 時，該由誰提供？我們的答案是使用者自己，而且完全不用把 key 交給 App。今天，這個專案有了正式的家。

## 有什麼新東西

- **開發者文件** [keyala.io/docs](https://keyala.io/docs/)：從第一個呼叫到用量儀表板的一頁式說明，附完整 API 一覽。同樣的內容也是一個 Markdown 檔，可以下載，或直接交給 AI 程式助理。
- **使用指南** [keyala.io/guide](https://keyala.io/guide/)，提供 English、繁體中文、日本語：登入、新增 key、連接 App、批准呼叫、設定上限與 OpenRouter。
- **網頁控制台** [app.keyala.io/console](https://app.keyala.io/console)：你的 key（只顯示最後四碼）、可以撤銷的已連接 App，以及請求歷史紀錄。開發者也能在這裡建立 App、查看每個 App 的報表。

## 在網頁上登入

用 Keyala App 掃描控制台上的 QR code 並點**批准網頁登入**，或用帳號電子郵件加上你在 App **設定 > 網頁密碼**設定的密碼。網頁登入有效 12 小時。

> 只批准你自己正在自己電腦上進行的網頁登入。不要批准別人傳給你的 code。

網頁控制台只能看，不能批准呼叫、新增或變更 key，也不能放寬 App 的權限。這些都只能在手機上做。

## 仍在 beta

Keyala 是個人營運的實驗性專案，beta 期間免費。iPhone App 目前為邀請制 TestFlight，想加入請寫信到 [support@keyala.io](mailto:support@keyala.io)。
