APP SETUP

Register your app

Create app credentials for server calls, or add allowed origins for a browser client.

Use the same server that issued your app token. For local testing, use http://127.0.0.1:8080.

The hosted free service clears report history, user grants, and provider keys when it restarts.

One line, comma-separated. Add exact origins, including scheme and port when used. HTTP is for localhost only.

If registration is blocked by your network or browser CORS settings, register through the API guide.

APP REGISTERED

Save your credentials

Your app token is shown once. Store it in a server-side secret manager. Keep it out of client code and version control.

Reservations and actuals are different. Estimated cost is a reservation used before a call. Known actual cost comes from provider usage data. Missing usage is left unpriced and is not counted as zero.

Rotate app token?

The old token stops working immediately. Update every service that uses it.

After a database reset, the old token may work until you use the replacement. Use persistent storage for durable revocation.
