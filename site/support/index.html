Help & contact

Need help with Keyala?

Contact

Email support@keyala.io. Include the app version, the selected server and the steps that failed. Never send API keys, authorization headers, passwords or private prompts.

Provider credits

Keyala beta is free. Model API usage is billed separately by your provider. ChatGPT and Claude subscriptions do not include API credit; OpenRouter has its own balance. Check the account or project that issued your key if a request reports insufficient credits.

Requests that do not finish

An uncertain request may already have reached the provider. Inspect its recorded status and provider usage before creating another request. Do not repeatedly resubmit it. Keyala does not automatically retry uncertain model calls.

Pairing and notifications

Start a connection from the AI app’s website, scan its QR, and verify the source shown on the phone. If it expires, start again on that website. When notifications are unavailable, open Inbox to see waiting requests.

Privacy

Read our privacy information. A bug report should use fictional content or redact personal data.

支援與聯絡

使用 Keyala 遇到問題嗎？

聯絡方式

請寄信至 support@keyala.io，附上 App 版本、使用的伺服器及發生問題的步驟。請勿寄送 API key、授權標頭、密碼或私人提示內容。

模型額度

Keyala beta 免費；模型 API 費用仍由你的 provider 另行收取。ChatGPT、Claude 訂閱不包含 API 額度，OpenRouter 也使用獨立餘額。若顯示額度不足，請確認建立該 key 的帳號或專案是否有可用額度。

請求沒有完成

狀態不確定的請求可能已送達 provider。建立另一筆請求前，請先查看原請求狀態及 provider 用量，不要反覆重送。Keyala 不會自動重試狀態不確定的模型請求。

配對與通知

從 AI 工具的網頁開始連結，掃描 QR code，並確認手機顯示的來源。配對過期時，請從該網頁重新開始。無法接收通知時，可開啟收件匣查看待處理請求。

隱私

請閱讀隱私說明。回報問題時，請使用虛構內容或遮蔽個人資料。

ヘルプとお問い合わせ

Keyala でお困りですか？

お問い合わせ

support@keyala.io に、アプリのバージョン、接続先サーバー、問題が起きた操作手順をお送りください。API キー、認証ヘッダー、パスワード、非公開のプロンプトは送らないでください。

API の残高

Keyala のベータ版は無料です。モデル API の利用料はプロバイダーから別途請求されます。ChatGPT や Claude のサブスクリプションに API の残高は含まれません。OpenRouter も独自の残高を使います。残高不足の場合は、キーを作成したアカウントやプロジェクトをご確認ください。

完了しないリクエスト

結果が不確定のリクエストは、すでにプロバイダーに届いている可能性があります。別のリクエストを作成する前に、元の状態とプロバイダーの利用状況を確認してください。Keyala は結果が不確定のモデル呼び出しを自動で再試行しません。

接続と通知

AI ツールのウェブサイトから接続を開始し、QR コードを読み取って、iPhone に表示される接続元を確認します。有効期限が切れた場合は、そのウェブサイトでやり直してください。通知を受け取れない場合は、受信トレイで確認できます。

プライバシー

プライバシーについてをご覧ください。不具合を報告する際は、架空の内容を使うか個人情報を伏せてください。
