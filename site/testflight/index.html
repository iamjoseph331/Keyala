Keyala TestFlight guide

Thanks for trying Keyala. Do as much as you have time for. An incomplete test or a note about where you got stuck is welcome.

The invite-only pilot will run for 14 days with a minimum of 10 and a maximum of 20 testers. Dates and the test build will be confirmed in the invitation.

Install and sign in

On an iPhone with iOS 17 or later, install Apple TestFlight from the App Store. Open Apple’s Keyala invitation, then choose View in TestFlight → Accept → Install. Check the version and build against the invitation.

Open Keyala and sign in with your own Apple or Google account. These create separate Keyala accounts even if the email matches. Keep using the same sign-in method and account throughout the pilot.

Seven things to try

Try each goal before opening its steps. If you get stuck, note where it happened, then open the details.

  1. Describe what you think Keyala does.

    After you see the first screens, write a sentence in your own words. Keep it for your feedback before reading any of the explanations below.

    After you’ve written it

    Keyala lets connected AI apps ask to make model calls. The apps receive revocable permissions and the results of approved calls. Keyala stores your API key encrypted on its server and uses it to send approved requests without handing the key to the connected app. You are trusting the Keyala server operator to handle that key. The pilot sponsor may see provider usage or logs, so use fictional inputs throughout.

  2. Add the pilot key.

    Show steps and test options

    For the free connected test, Joseph sends each tester a private OpenRouter key with a US$1 spending limit. You can paste it without an OpenRouter account or OAuth sign-in.

    The US$1 is the total for the pilot. It does not reset or get topped up automatically. The key expires at the end of the shared 14-day pilot, on the date in your personal invitation. How far it goes depends on usage. If the credit runs out, stop there. Keyala does not automatically fall back to a paid key.

    In Keyala, open Keys → Paste a key on this iPhone. Choose OpenRouter under Provider, paste the key and tap Save key. If you already have your own OpenRouter key in Keyala, keep it and tell Joseph before adding a pilot key. Using your own key uses your provider balance and may incur charges.

    For an offline tour, go to Settings → Developer options, enable developer options and turn on Use sample data. Switching signs you out. Offline samples make no network calls and cannot verify live connections or billing. Turn samples off and sign back in with the same account before continuing the connected test.

  3. Connect Interview Prepper to Keyala.

    Show steps

    Before pairing, choose your billing route. For the sponsored or your own OpenRouter key, turn on Settings → Use OpenRouter for OpenAI and Anthropic. To use your own Anthropic key directly, leave this switch off and check that your Anthropic key is saved. Existing connections retain their billing route. To change it, disconnect Interview Prepper in Keyala and reconnect.

    Open Interview Prepper and choose Connect Keyala. Open the pairing link on the iPhone or scan the QR code from another screen. If either fails, enter the KY- code in Keyala. Confirm Interview Prepper and the billing route you chose, then choose Connect and ask each time to start with Ask.

  4. Review a request and approve it once.

    Show steps and a fictional example

    In Interview Prepper, set the level to Junior, choose Machine learning fundamentals under Categories and set Questions to 1. Under Graded session → Configure, select Haiku 5.5 (claude-haiku-5-5 in the model list shown after Keyala connects). Tap Start graded session to generate a question for a fictional junior AI/ML interview.

    Keep Keyala open for the first attempt. In Inbox, check the request text, model, estimated cost and billing route. Select This call only and tap Allow. Check that Interview Prepper receives a response. A graded session can trigger several calls. Keep each approval separate and review or deny any follow-up before it runs.

  5. Deny a request.

    Show steps

    Use the next pending request. If you have a question and there’s no request waiting, enter a short fictional answer and tap Submit to request grading. For example, if asked about overfitting, write “In a fictional project, I’d compare training and validation errors.” Tap Deny in Keyala and see what Interview Prepper shows. If the page moves on, check Activity for the denial.

  6. Find what happened to the requests.

    Show steps

    Open Inbox → Activity and look for the approved and denied requests. Check their statuses and, where shown, the model, route and cost. Keyala’s estimates and usage-based costs can differ from the provider’s bill.

  7. Revoke the connection and see what happens on the next attempt.

    Show steps

    Open Apps → Interview Prepper → Disconnect app and confirm. In Interview Prepper, choose New session if you’re on the results screen, then try Start graded session once. Check that the page asks you to reconnect. A request already sent upstream may still finish. You can end the test when asked to reconnect.

If a step fails or a request is marked uncertain, stop there. Check Activity and report what you saw. Skip repeated attempts that could spend more credit.

Optional checks

  • Allow notifications, lock your iPhone and check whether a request notification opens the right screen. If none arrives, open Keyala and check Inbox.
  • Change Keyala’s language, reopen the app and check that your choice is saved.

Keep your account for the pilot. Account deletion is irreversible and is outside the test tasks.

Coupon sharing is a future concept. There’s no coupon flow to test or announced pricing or release date. The US$1 pilot keys are supplied manually for this test.

Send feedback

Open the English feedback form. Feedback is optional and needs no sign-in. You can send it even if you could not install Keyala.

For bugs, reply to the introductory email or email support@keyala.io. You can also open TestFlight → Keyala → Send Beta Feedback. Apple also receives feedback submitted there.

You can include the Keyala version and build, iPhone model, iOS version, app language, date and time zone, steps, expected and actual results, provider and model, or a request ID sent privately to support. Screenshots are optional. Hide keys, passwords, tokens, pairing codes and QR codes, personal information and private prompts or replies before sharing.

Keyala TestFlight 測試指南

謝謝你願意試用 Keyala！有空做到哪裡就好。即使只試了幾步，告訴我們在哪裡卡住也很有幫助。

這次採邀請制，測試為期 14 天，最少 10 人、最多 20 人。確切日期和測試版本會在邀請中確認。

安裝與登入

使用 iOS 17 以上的 iPhone，在 App Store 安裝 Apple 的 TestFlight。開啟 Apple 寄來的 Keyala 邀請，依序點選在 TestFlight 中查看、接受、安裝。比對邀請中的版本與組建編號。

開啟 Keyala，使用自己的 Apple 或 Google 帳號登入。即使電子郵件相同，兩種方式也會建立各自獨立的 Keyala 帳號。測試期間請固定使用同一種登入方式和同一個帳號。

七個測試任務

請先看目標並試著完成。卡住時先記下卡在哪裡，再展開步驟。

  1. 用自己的話說明 Keyala 的用途。

    看完 App 的開場畫面後，先寫一句你對 Keyala 的理解，再往下讀說明。請把這句話留到回饋時使用。

    寫完後再展開

    與 Keyala 連結的 AI 工具可以提出模型呼叫請求，並取得可撤銷的授權與你批准的呼叫結果。Keyala 將 API 金鑰加密存放在伺服器，並使用金鑰轉送你批准的請求。連結的工具不會取得金鑰。使用時，你需要信任 Keyala 的伺服器營運者會妥善處理金鑰。測試贊助者可能看得到服務商用量或紀錄，請全程使用虛構資料。

  2. 新增測試用金鑰。

    查看步驟與測試方式

    若要免費測試連線流程，Joseph 會私下提供每人一把支出上限為 1 美元的 OpenRouter 金鑰。直接貼上即可，無須 OpenRouter 帳號或 OAuth 登入。

    1 美元是整段測試的總上限，額度不會重設或自動補充。所有人的金鑰會在共同的 14 天測試結束時到期，日期以個別邀請為準。可呼叫幾次取決於實際用量。額度用完就先停止，Keyala 不會自動改用其他付費金鑰。

    在 Keyala 開啟 Keys → 在這台 iPhone 貼上 key。在服務商選擇 OpenRouter，貼上金鑰後點儲存 key。若 Keyala 已有你自己的 OpenRouter 金鑰，請保留原金鑰，新增測試金鑰前先聯絡 Joseph。使用自帶金鑰會消耗你自己的服務商餘額，可能產生費用。

    若只想離線看介面，可到設定 → 開發者選項，啟用開發者選項後開啟使用範例資料。切換會登出。離線範例不會發出網路請求，無法驗證實際連線或計費。要繼續連線測試時，先關閉範例，再以原帳號登入。

  3. 將 Interview Prepper 連結到 Keyala。

    查看步驟

    配對前先選擇計費路徑。使用測試金鑰或自己的 OpenRouter 金鑰時，在設定開啟透過 OpenRouter 使用 OpenAI 與 Anthropic。要直接使用自帶的 Anthropic 金鑰，請保持這個開關關閉，並確認已儲存 Anthropic 金鑰。既有連結會保留原計費路徑。要變更時，請先在 Keyala 中斷 Interview Prepper 的連結，再重新配對。

    開啟 Interview Prepper，選擇 Connect Keyala。在 iPhone 開啟配對連結，或掃描另一個螢幕上的 QR 碼。失敗時可在 Keyala 輸入 KY- 代碼。確認是 Interview Prepper，且計費路徑符合你的選擇，再選擇連結並每次詢問，初始權限保持逐次詢問（Ask）。

  4. 檢查一筆請求，只批准這一次。

    查看步驟及虛構範例

    在 Interview Prepper 選 Junior，在 Categories 選 Machine learning fundamentals，將 Questions 設為 1。開啟 Graded session → Configure，選 Haiku 5.5（與 Keyala 連結後的模型清單中對應 claude-haiku-5-5）。點 Start graded session，為虛構的初階 AI／機器學習工程師面試產生一道題目。

    首次測試先讓 Keyala 保持開啟。在收件匣確認請求內容、模型、預估費用及計費路徑，選僅這次呼叫並點允許。確認 Interview Prepper 有收到回應。一次評分練習可能觸發多筆呼叫，請逐筆檢查，再決定允許或拒絕後續請求。

  5. 拒絕一筆請求。

    查看步驟

    使用下一筆待處理請求。若題目已出現且沒有待處理請求，可填一段虛構的短答案，點 Submit 送出評分請求。例如題目問過擬合，可以回答：「在虛構專案中，我會比較訓練和驗證誤差。」在 Keyala 點拒絕，觀察 Interview Prepper 的畫面。若畫面已跳轉，可到活動紀錄查看拒絕結果。

  6. 找出請求的處理結果。

    查看步驟

    開啟收件匣 → 活動紀錄，找出批准與拒絕的請求。查看狀態，以及畫面上有顯示的模型、計費路徑與費用。Keyala 顯示的預估金額和依用量計算的費用可能與服務商帳單不同。

  7. 撤銷連結，確認下次使用時會發生什麼。

    查看步驟

    開啟 Apps → Interview Prepper → 中斷 App 連結並確認。回到 Interview Prepper，若在結果頁就選 New session，再試按一次 Start graded session。確認頁面要求重新連結。先前已送往服務商的請求仍可能完成。看到重新連結的提示就可結束。

步驟失敗或請求顯示結果不確定（uncertain）時，請先停下來。查看活動紀錄，回報看到的情況即可。無須反覆重送並消耗更多額度。

有空再試

  • 允許通知後鎖定 iPhone，確認點通知會開啟對應請求。沒收到通知時，可開啟 Keyala 查看收件匣。
  • 切換 Keyala 語言，重新開啟 App，確認語言設定有保留。

測試期間請保留帳號。刪除帳號無法復原，這次不用測試。

分享優惠券是未來的構想，功能尚未實作，也尚未公布價格與推出日期。此次 1 美元的測試金鑰由專案方手動提供。

提供回饋

填寫繁體中文回饋表。回饋可自由填寫，無須登入。即使沒能安裝 Keyala，也歡迎告訴我們遇到了什麼。

遇到問題時，請直接回覆介紹信，或寄信至 support@keyala.io。也可從 TestFlight → Keyala → 傳送 Beta 版回饋回報，透過此途徑送出的回饋也會傳給 Apple。

可附 Keyala 版本與組建編號、iPhone 機型、iOS 版本、App 語言、日期時間與時區、操作步驟、預期與實際結果、服務商與模型。若有請求 ID，可私下提供給支援。截圖可省略。分享前請遮蔽金鑰、密碼、權杖、配對代碼與 QR 碼、個資及私人提示詞與回覆。

Keyala TestFlight テストガイド

Keyala を試していただき、ありがとうございます。時間のある範囲でお試しください。途中まででも、どこで困ったかを教えていただけると助かります。

今回は招待制で、期間は14日間、参加人数は10〜20人です。日程と対象ビルドは招待時にお知らせします。

インストールとサインイン

iOS 17 以降の iPhone に、App Store から Apple の TestFlight を入れます。Apple から届いた Keyala の招待を開き、TestFlight で表示 → 承認 → インストールの順に進みます。バージョンとビルド番号を招待の案内と照合してください。

Keyala を開き、ご自身の Apple Account または Google アカウントでサインインします。メールアドレスが同じでも、別々の Keyala アカウントになります。テスト期間中は同じサインイン方法とアカウントを使ってください。

試していただきたい7つのこと

まず各項目の目標を読んで試してみてください。途中で困ったら、どこで困ったかをメモしてから手順を開いてください。

  1. Keyala が何をするアプリだと思ったか、自分の言葉で説明する。

    最初の画面を見たら、ガイドの説明を読む前に、ご自身の言葉で一文書いてください。あとでフィードバックに使えるように残しておいてください。

    書き終えたら開く

    Keyala に接続した AI アプリは、モデルの呼び出しをリクエストできます。AI アプリが受け取るのは、取り消し可能な権限と、許可された呼び出しの結果です。Keyala は API キーを暗号化してサーバーに保存し、許可されたリクエストを送る際に使います。接続した AI アプリにキーが渡ることはありません。利用するには、Keyala のサーバー運営者にキーの取り扱いを任せることになります。テストの費用を負担する側がプロバイダーの利用状況やログを確認できる場合があるので、入力には架空の内容を使ってください。

  2. テスト用のキーを追加する。

    手順とテスト方法を表示

    無料の接続テストには、Joseph が一人ずつ個別にお渡しする、利用上限が1米ドルの OpenRouter キーを使えます。キーを貼り付けるだけなので、OpenRouter のアカウントや OAuth での認証は不要です。

    1米ドルはテスト期間全体の上限です。残高はリセットされず、自動で追加されることもありません。キーは共通の14日間のテストが終わると失効します。終了日は個別の招待をご確認ください。呼び出せる回数は使い方によって変わります。残高を使い切ったらそこで止めてください。Keyala が別の有料キーに自動で切り替えることはありません。

    Keyala で キー → この iPhone にキーを貼り付けを開きます。プロバイダーで OpenRouter を選び、キーを貼り付け、キーを保存を押します。ご自身の OpenRouter キーをすでに Keyala に登録している方は、そのまま残し、テスト用キーを追加する前に Joseph にお知らせください。ご自身のキーを使う場合は、プロバイダーの残高を使い、料金が発生することがあります。

    画面だけ試す場合は、設定 → 開発者向け設定で開発者向け設定を有効にし、サンプルデータを使用をオンにします。切り替えるとサインアウトします。サンプルはオフラインで動作し、通信しないため、実際の接続や課金は確認できません。接続テストに進むときはサンプルをオフにし、元のアカウントでサインインし直してください。

  3. Interview Prepper を Keyala に接続する。

    手順を表示

    接続する前に請求先を選びます。今回お渡しするキーやご自身の OpenRouter キーを使う場合は、設定の OpenAI と Anthropic に OpenRouter を使うをオンにします。ご自身の Anthropic キーで直接利用する場合は、スイッチをオフにし、Anthropic キーが登録済みであることを確認します。既存の接続は以前の請求先を使い続けます。変える場合は、Keyala で Interview Prepper の接続を解除してからつなぎ直してください。

    Interview Prepper を開き、Connect Keyala を選びます。iPhone で接続リンクを開くか、別の画面に表示した QR コードを読み取ります。うまくいかない場合は Keyala で KY- コードを入力します。Interview Prepper への接続で、請求先が選んだものになっていることを確認し、接続して毎回確認を選びます。最初は毎回確認（Ask）のまま進めます。

  4. リクエストを確認し、1回だけ許可する。

    手順と架空の例を表示

    Interview Prepper で Junior、Categories で Machine learning fundamentals を選び、Questions は 1 にします。Graded session → Configure で Haiku 5.5 を選びます（Keyala に接続した後に表示される一覧の claude-haiku-5-5）。Start graded session を押し、架空の若手 AI・機械学習エンジニアの面接用に質問を1件作ります。

    初回は Keyala を開いておきます。受信トレイでリクエストの内容、モデル、概算費用、請求先を確認します。今回の呼び出しのみを選んで許可をタップし、Interview Prepper に応答が返ることを確認します。採点付きセッションでは複数の呼び出しが発生することがあります。後続のリクエストも1件ずつ確認し、許可するか拒否するかを決めてください。

  5. リクエストを拒否する。

    手順を表示

    次の確認待ちのリクエストを使います。質問が表示され、確認待ちのリクエストがない場合は、架空の短い回答を入力し、Submit を押して採点を依頼します。過学習について聞かれたら、例えば「架空のプロジェクトで、訓練と検証の誤差を比べます」と書きます。Keyala で拒否をタップし、Interview Prepper の表示を確認します。画面が切り替わったら、履歴で拒否を確認できます。

  6. リクエストの結果を確認する。

    手順を表示

    受信トレイ → 履歴を開き、許可したものと拒否したものを探します。ステータスと、表示されている場合はモデル、請求先、費用を確認してください。Keyala に表示される概算額や使用量からの計算額は、プロバイダーの請求額と異なる場合があります。

  7. 接続を解除し、次に使おうとするとどうなるか確かめる。

    手順を表示

    アプリ → Interview Prepper → アプリの接続を解除を開き、解除を確定します。Interview Prepper に戻り、結果画面にいる場合は New session を選びます。Start graded session を1回押し、再接続を求められることを確認します。すでにプロバイダーに送信済みのリクエストは完了することがあります。再接続の案内が出たらそこで終了できます。

手順がうまくいかないときや、リクエストが結果不明（uncertain）の場合は、そこで止めてください。履歴で状況を確認し、気づいたことをお知らせください。再現のために残高を使って繰り返す必要はありません。

時間があれば試すこと

  • 通知を許可して iPhone をロックし、通知をタップしたときに該当するリクエストが開くか確認します。通知が来なければ、Keyala を開いて受信トレイを確認してください。
  • Keyala の言語を変更し、アプリを開き直しても設定が残るか確認します。

テスト期間中はアカウントを残しておいてください。削除は元に戻せないため、テスト項目に含めていません。

クーポンの共有は今後の構想です。機能は未実装で、価格と提供開始日は未発表です。今回の1米ドル分のキーは、このテストのために個別にお渡しします。

フィードバックを送る

日本語のフィードバックフォームを開く。回答は任意で、ログインは不要です。Keyala をインストールできなかった場合も送信できます。

不具合は、案内メールへの返信か support@keyala.io へお願いします。TestFlight → Keyala → ベータ版フィードバックを送信でも報告できます。TestFlight から送った内容は Apple にも届きます。

必要に応じて、Keyala のバージョンとビルド番号、iPhone の機種、iOS のバージョン、アプリの言語、日時とタイムゾーン、手順、期待した結果と実際の結果、プロバイダーとモデルを添えてください。リクエスト ID は必要な場合にのみ、サポートへ個別にお送りください。スクリーンショットは任意です。共有前にキー、パスワード、トークン、接続コードと QR コード、個人情報、非公開の入力や応答を隠してください。
